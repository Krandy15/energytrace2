# Frontend — Electricity Theft Detection dashboard

React + Vite. Runs entirely on local JSON data — no backend required.

## Setup

```bash
npm install
npm run dev
```

Opens on `http://localhost:5173`.

```bash
npm run build      # production build -> dist/
npm run preview    # preview the production build locally
```

## Data sources (no backend yet)

- `src/pages/Dashboard.jsx` imports `src/data/mock_400_nodes.json` directly.
- `src/pages/DemoHighlights.jsx` and `src/api/client.js` read `public/scores.json`
  at runtime via `fetch('/scores.json')`.
- `src/pages/AccountDetail.jsx` uses a small hardcoded telemetry sample for its chart.

Both `src/data/*.json` files are generated by the scripts in `../ai/scripts/`
(see `../ai/README.md`) — regenerate them any time from there.

## Routes

| Path                  | Page             |
|------------------------|------------------|
| `/`                    | Landing          |
| `/dashboard`            | Dashboard        |
| `/account/:accountId`   | AccountDetail    |
| `/demo`                 | DemoHighlights   |

## Files

- `src/api/client.js` — all "backend" calls go through here. Currently reads
  local files; once `../backend` is live, swap the internals for real
  `fetch()` calls against `VITE_API_URL` — nothing else needs to change.
- `src/utils/risk.js` — single place that maps a risk_score to a color/label,
  so Dashboard and AccountDetail never disagree on what "high risk" means.
- `src/styles/theme.css` — all colors/fonts as CSS variables.
- `src/mocks/` — hand-written example payloads matching the shape a real
  backend should return (see `../backend/README.md`); not currently imported
  by any component.

## Connecting a real backend later

1. Copy `.env.example` to `.env` and set `VITE_API_URL`.
2. Update `src/api/client.js` to call the real endpoints instead of reading
   local JSON.
3. `vite.config.js` already proxies `/accounts`, `/model`, `/inspections`,
   `/audit`, `/simulate` to `localhost:8000` in dev — no changes needed there
   as long as the backend serves those paths.
